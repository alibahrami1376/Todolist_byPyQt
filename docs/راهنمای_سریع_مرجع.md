# 🚀 راهنمای سریع مرجع - TodoList Project

این فایل یک مرجع سریع برای توسعه‌دهندگان است.

---

## 📍 مسیرهای مهم

### نقطه شروع
- `main.py` → شروع برنامه

### پیکربندی
- `configg/config_pages.py` → ساخت صفحات و کنترلرها
- `configg/page_registery.py` → ثبت صفحات

### لایه‌های معماری

#### View (رابط کاربری)
- `views/main_frameless_window.py` → پنجره اصلی
- `views/pages/` → صفحات مختلف
- `views/widgets/` → ویجت‌های قابل استفاده مجدد

#### Controller (کنترلر)
- `controllers/task_controller.py` → کنترلر کارها
- `controllers/auth_controller.py` → کنترلر احراز هویت

#### Service (منطق کسب‌وکار)
- `services/task_service.py` → سرویس کارها
- `services/user_service.py` → سرویس کاربران
- `services/db_session.py` → اتصال پایگاه داده

#### Model (مدل داده)
- `models/task_models.py` → Domain Model کارها
- `models/db/task_entity.py` → Entity کارها (دیتابیس)
- `mapper/task_mapper.py` → تبدیل Model ↔ Entity

#### Session (جلسه)
- `core/session_manager.py` → مدیریت Session کاربر
- `core/session_task.py` → Session کارها

## 📦 ساختار فایل‌های مهم

### ساختار یک صفحه کامل
```python
from PyQt6.QtWidgets import QWidget, QVBoxLayout
from PyQt6.QtCore import pyqtSignal

class MyPage(QWidget):
    # 1. تعریف Signals
    handle_action = pyqtSignal(str)
    
    def __init__(self):
        super().__init__()
        # 2. اتصال Signals خارجی
        # 3. ساخت UI
        self.init_ui()
    
    def init_ui(self):
        layout = QVBoxLayout(self)
        # ساخت ویجت‌ها
        # ...
    
    def some_method(self):
        # 4. فراخوانی Signal
        self.handle_action.emit("data")
```

### ساختار یک Service کامل
```python
from typing import List
from services.db_session import get_session
from models.db.my_entity import MyEntity

class MyService:
    def __init__(self):
        pass
    
    def get_all(self) -> List[MyEntity]:
        with get_session() as db:
            return db.query(MyEntity).all()
    
    def get_by_id(self, id: str) -> MyEntity:
        with get_session() as db:
            return db.get(MyEntity, id)
    
    def add(self, entity: MyEntity) -> MyEntity:
        with get_session() as db:
            db.add(entity)
            db.commit()
            db.refresh(entity)
            return entity
    
    def update(self, entity: MyEntity):
        with get_session() as db:
            db.merge(entity)
            db.commit()
    
    def delete(self, id: str):
        with get_session() as db:
            entity = db.get(MyEntity, id)
            if entity:
                db.delete(entity)
                db.commit()
```

## ⚠️ نکات مهم

1. **همیشه از `with get_session()` استفاده کنید** - Session به صورت خودکار بسته می‌شود
2. **بعد از `db.add()` حتماً `db.commit()` بزنید** - تغییرات ذخیره نمی‌شوند
3. **Signals را در `__init__` تعریف کنید** - قبل از `super().__init__()`
4. **از `Session.is_guest()` برای بررسی حالت مهمان استفاده کنید**
5. **Migration ها را قبل از تغییر Entity اجرا کنید**
