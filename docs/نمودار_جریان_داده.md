## 💡 نکات مهم در جریان داده

1. **همیشه از Signals برای ارتباط بین View و Controller استفاده کنید**
2. **Session برای نگه‌داری داده در حافظه است (برای سرعت)**
3. **Service برای دسترسی به پایگاه داده است**
4. **Mapper برای تبدیل بین Model و Entity است**
5. **Controller هماهنگی بین View و Service را انجام می‌دهد**
